#🚚 Supply Chain Analysis using Linear Regression 📊

📌 Project Overview

This project focuses on predicting Product Delivery Time Days for customer orders using various Supply Chain features such as shipment mode, warehouse distance, product weight, processing time, and shipping cost.

The project uses the Linear Regression Machine Learning Algorithm to analyze logistics patterns and build a predictive model for delivery performance.

🎯 Project Goal
🔍 Goal of the Project

The main goal of this project is to:

📦 Predict Delivery_Time_Days for an order using supply chain features.

The model helps businesses:

Improve delivery planning 🚚
Optimize logistics operations 📍
Reduce delays ⏳
Enhance customer satisfaction 😊
Improve supply chain efficiency 📈

📂 Dataset Features

The dataset contains realistic supply chain variables:

Feature	Description
📦 product	Product name
🏷️ product_category	Product category
📍 warehouse_dist_km	Distance from warehouse
⚖️ product_weight_kg	Weight of product
🚚 shipment_mode	Transportation mode
⏳ warehouse_processing_time_days	Warehouse handling time
📈 demand_forecast_unit	Forecasted product demand
💵 shipping_cost	Shipping expense
🎯 delivery_time_days	Target variable
🤖 Machine Learning Model
📌 Algorithm Used:
Linear Regression

Linear Regression is used to predict:

🎯 Delivery_Time_Days

based on:

Distance 📍
Shipment Mode 🚚
Product Weight ⚖️
Processing Time ⏳
Shipping Cost 💰
📊 Key Insights

✅ Longer distances increase delivery time 📍
✅ Air shipment delivers faster than Road/Rail ✈️
✅ Processing delays affect final delivery ⏳
✅ Heavy products may require slower transport 🚛
✅ Shipping cost is highly related to logistics distance 💰

📈 Model Performance

✔️ Achieved approximately 95% model evaluation accuracy due to strong relationships between supply chain variables and delivery time.
